| Поле | Значение |
|------|----------|
| **Проект** | Автоучёт — desktop-приложение учёта расходов на автомобиль |
| **Документ** | Project Glossary |
| **Версия** | 0.1 |
| **Автор** | Ройко Артём Андреевич, группа 450502 |
| **Дата** | 21.11.2026 |
| **Связанные документы** | `srs.md`, `sdd/avtouchet-sdd.md`, `docs/supplementary-specs.md` |

## Назначение

Глоссарий задаёт единые определения терминов предметной области и проектных артефактов для SRS, SDD, UML-диаграмм и дополнительных спецификаций лабораторной работы № 5.

## Глоссарий

| № | Термин | Англ. | Определение |
|---|--------|-------|-------------|
| 1 | Актёр | Actor | Внешняя роль относительно границы системы. В версии 0.1 — владелец автомобиля; внешних сервисов нет |
| 2 | Прецедент | Use Case | Типовой сценарий взаимодействия актёра с системой, дающий измеримый результат |
| 3 | Поток событий | Flow of Events | Описание обработки в прецеденте: краткое описание, предусловия, основной и альтернативные потоки, постусловия |
| 4 | Карточка автомобиля | Car card | Запись об одном автомобиле: название и текущий пробег в километрах |
| 5 | Расход | Expense | Одна уже совершённая трата: категория, дата, сумма в BYN, необязательные комментарий и показание пробега |
| 6 | Категория расхода | Expense category | Одно из значений: топливо, страховка, налог, ремонт, прочее (`FUEL`, `INSURANCE`, `TAX`, `REPAIR`, `OTHER`) |
| 7 | Период | Period | Отрезок календарных дат с включительными границами; по умолчанию — текущий календарный месяц |
| 8 | Сводка | Ownership summary | Итог стоимости владения за период, суммы по пяти категориям и цена километра либо признак нехватки пробега |
| 9 | Стоимость владения | Ownership cost | Сумма всех расходов за выбранный период |
| 10 | Стоимость километра | Cost per kilometre | Стоимость владения, делённая на разность максимального и минимального указанных пробегов за период |
| 11 | Журнал | Ledger | Локальный JSON-файл `{user.home}/Avtouchet/ledger.json` с карточкой и списком расходов |
| 12 | Черновик расхода | Expense draft | Состояние полей формы до успешной проверки; в журнал не записывается |
| 13 | Сравнение периодов | Period comparison | Показ двух сводок и разности итогов (второй период минус первый) на главном экране |
| 14 | Владелец автомобиля | Car owner | Единственный актёр версии 0.1: ведёт карточку, журнал и смотрит сводки |
| 15 | MVP / версия 0.1 | Minimum Viable Product | Согласованный релиз до 20.12.2026: журнал одного автомобиля без сети, без графика и без ИИ |
| 16 | SRS | Software Requirements Specification | Спецификация требований к ПО (`srs.md`) |
| 17 | SDD | Software Design Description | Описание дизайна (`sdd/avtouchet-sdd.md`) |
| 18 | ADR | Architectural Decision Record | Протокол одного архитектурного решения (`docs/decisions/`) |
| 19 | UML | Unified Modeling Language | Язык моделирования структуры и поведения системы |
| 20 | Include | Include | Связь включения обязательного фрагмента поведения в прецедент |
| 21 | EDT | Event Dispatch Thread | Поток Swing, на котором выполняются окна и обработчики версии 0.1 |
